# Changelog

All notable user-facing changes are documented here. Versions follow semantic versioning while the project is pre-1.0.

## 0.4.8 — 2026-08-12

- Added task-conditioned `qgis_context` packs with strict byte budgets.
- Reduced the default catalog to seven tools and added confidence-based schema disclosure.
- Added dual-era MCP support through 2026-07-28 and the negotiated MCP Tasks extension.
- Added declarative batch references, JSON Pointer projections and bounded capture modes.
- Added privacy-safe recent error hints and append-only crash diagnostics.
- Added intelligent official QGIS plugin discovery and confirmation-gated installation.
- Added compatibility, maintenance, popularity and risk ranking for official plugin candidates.
- Hardened official-catalog access with strict HTTPS origin checks, redirect validation and safe XML parsing.
- Added Claude Desktop setup, safe migration of recognized legacy `qgis-mcp` client entries across every supported connector, and distinct bridge-registration diagnostics.

## 0.4.7 — 2026-08-07

- Added MCP 2025-11-25 support, protocol-correct cancellation and structured tool errors.
- Added enriched tool schemas, federated discovery, paged resources and fair scheduling.
- Reduced inline result and snapshot context costs.
