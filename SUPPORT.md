# Support

## Usage and setup help

Ask in [GitHub Discussions Q&A](https://github.com/Aaa2122/QGIS-MCP/discussions/categories/q-a). Include your QGIS version, operating system, MCP client, plugin version and the exact step that failed.

Before asking, try:

1. upgrading to the latest release;
2. using **Connect / Repair** from the QGIS plugin;
3. restarting QGIS and the MCP client;
4. checking `qgis_diagnostics` without sharing credentials or private data.

## Bugs and feature requests

Use the structured [Issue forms](https://github.com/Aaa2122/QGIS-MCP/issues/new/choose) for reproducible bugs and implementation-ready requests. Early ideas belong in [Ideas Discussions](https://github.com/Aaa2122/QGIS-MCP/discussions/categories/ideas).

## Security and conduct

- Report vulnerabilities through [SECURITY.md](SECURITY.md), never through a public Issue.
- Report community safety concerns through [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Support is provided by maintainers and community volunteers on a best-effort basis. There is currently no guaranteed response time or commercial support agreement.
